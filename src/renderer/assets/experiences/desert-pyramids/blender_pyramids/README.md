# Pyramids Region (desert vista)

Open desert plateau for OnePad: sand dunes, rocks, palm clusters, camels,
Sphinx, obelisks, and Giza pyramids on the horizon. The circular desk sits
in a clear center island.

## Paths
- Blend: `blender/pyramids/1/desert_pyramids.blend`
- Runtime GLB: `desert_pyramids.glb`
